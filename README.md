# עברית מלאה ל-Claude Code

תוסף שגורם ל-Claude Code לעבוד כולו בעברית. זה כולל את התשובות, את הודעות הביניים הקצרות, את המחשבות, את תיאורי הפעולות ואת רשימת המשימות. בנוסף, התוסף מסדר את התצוגה כך שהעברית תיראה טוב מימין לשמאל.

## מה התוסף עושה

- **הנחיות מלאות:** סעיף בעברית נכנס ל-system prompt של הסשן. הוא מגדיר מה נכתב בעברית ואיך לכתוב כך שהטקסט ייראה טוב מימין לשמאל. ההנחיות מצורפות גם להודעה הראשונה ושוב כל עשר הודעות, ומועברות לכל סוכן משנה כשהוא מתחיל לרוץ.
- **תזכורות:** תזכורת קצרה מצטרפת לכל הודעה שלך, ואחרי כל כלי שהפלט שלו ארוך ובאנגלית. זה בדיוק הרגע שבו המודל נוטה לעבור לאנגלית.
- **עצירת פעולות באנגלית:** אם טקסט של פעולה שמוצגת לך כתוב באנגלית, התוסף עוצר את הקריאה ו-Claude שולח אותה שוב בעברית. זה חל על ה-`description` של פקודה, על התיאור, השלבים והתוויות של workflow, על רשימת המשימות (גם בטרמינל), על שאלות, על הודעות והתראות, על פעולות בדפדפן ובמחשב ועל הסיכום בסוף התור. כל טקסט נעצר פעם אחת בלבד: אם Claude שולח אותו שוב בלי שינוי, למשל כי הוא ציטוט מדויק, הוא עובר.
- **בדיקה בסוף התור:** אם Claude כתב לך משפטים באנגלית במהלך התור, הוא מתבקש פעם אחת לכתוב אותם מחדש בעברית. קוד, ציטוטים וטבלאות לא נספרים, והבדיקה לא רצה בתור שבו ביקשתם אנגלית או תרגום.
- **תצוגה מימין לשמאל:** בכל שורה שיש בה עברית, התוסף מוסיף לתצוגה תו כיווניות בלתי נראה (RLM). כך השורה מוצגת מימין לשמאל, והנקודה נשארת בסוף המשפט ולא קופצת להתחלה. ההודעה השמורה לא משתנה, ובלוקי קוד נשארים כמו שהם.
- **הפקודה `/hebrew`:** הפקודה `‎/hebrew off‎` משהה את האכיפה בסשן הנוכחי, למשל כשצריך לכתוב מסמך באנגלית, ו-Claude מקבל הודעה שמותר לו לכתוב באנגלית. הפקודה `‎/hebrew on‎` מחזירה אותה.

## התקנה

### באפליקציית Claude (לשונית Code)

1. לחצו על + ליד תיבת ההודעה, ואז על Plugins.
2. בחרו Add marketplace והדביקו: `avraham12200540/claude-code-hebrew`
3. לחצו Add plugin ליד hebrew-rtl.

### בטרמינל

בתוך סשן של Claude Code:

```
/plugin install hebrew-rtl --marketplace avraham12200540/claude-code-hebrew
```

או משורת הפקודה:

```bash
claude plugin install hebrew-rtl --marketplace avraham12200540/claude-code-hebrew
```

בהתקנה, ענו `y` להוספת ה-marketplace, ובחרו את ה-scope של המשתמש (user). התוסף יפעל בכל סשן חדש.

### בלי התוסף

אם הגרסה שלכם של Claude Code ישנה, או שאתם משתמשים ב-claude.ai, אפשר להעתיק את ההנחיות ידנית. התוכן נמצא בקובץ [HEBREW.md](HEBREW.md). ב-Claude Code מדביקים אותו בסוף הקובץ `~/.claude/CLAUDE.md`. ב-claude.ai מדביקים אותו בהעדפות האישיות שבהגדרות. בלי התוסף אין עצירה של פעולות באנגלית ואין סימוני כיווניות, אבל ההנחיות עצמן עובדות.

## הגדרות

| הגדרה | ברירת מחדל | מה היא עושה |
| --- | --- | --- |
| עצירת פעולות באנגלית (`enforce`) | פעיל | עוצר קריאה לכלי כשהתיאור שלה, שמוצג לכם, כתוב באנגלית |
| בדיקה בסוף התור (`stopCheck`) | פעיל | מבקש פעם אחת לכתוב מחדש בעברית משפטים שנכתבו באנגלית |
| תזכורות (`reminders`) | פעיל | תזכורת קצרה בכל הודעה, ואחרי כלי שהפלט שלו באנגלית |
| תצוגה מימין לשמאל (`rtlDisplay`) | פעיל | סימוני כיווניות בתצוגה של שורות בעברית |
| הערות בקוד (`codeComments`) | `match` | ‏`match`: עברית בקבצים חדשים, ואנגלית בקבצים שההערות בהם כבר באנגלית. ‏`hebrew`: תמיד עברית. ‏`english`: תמיד אנגלית |

משנים את ההגדרות בתפריט ההגדרות של Claude Code (`/config`), תחת השם של התוסף.

## מה התוסף לא יכול לעשות

- **המחשבות:** אי אפשר לכפות שפה על החשיבה של המודל. ההנחיות מבקשות ממנו לחשוב בעברית, ולרוב זה עובד, אבל לא תמיד.
- **האפליקציה עצמה:** לשונית Code של Claude קובעת את הכיוון של כל פסקה לפי האות הראשונה שלה, והתוסף דואג שהאות הזו תהיה עברית. לפריסת החלון, לכפתורים ולתפריטים אין לתוסף גישה.
- **טקסט של הממשק:** שמות של כפתורים ותפריטים של האפליקציה נשארים כפי שהם.
- **תוכן שנשלח לאחרים:** הודעות commit, תיאורי PR ומסמכים נכתבים בשפה שבה עובדים במאגר, כדי לא לשבור פרויקטים משותפים.

## דרישות

נדרשת גרסה עדכנית של Claude Code שתומכת בתוספים מסוג function hooks. התוסף נבדק על גרסה 2.1.299. בגרסה ישנה יותר, השתמשו ב-[HEBREW.md](HEBREW.md).

### בארגון שמנהל את Claude Code

כשארגון מנהל את Claude Code בהגדרות מנוהלות, חלק מהאירועים לא רצים בתוספים שמשתמש מתקין בעצמו: ה-system prompt, ההנחיות לסוכני משנה והבדיקה בסוף התור. שאר התוסף ממשיך לעבוד: ההנחיות המלאות שמצורפות להודעות, התזכורות, עצירת הפעולות באנגלית, ההערה בתיאור הכלים וסימוני הכיווניות.

## פיתוח

- להרצת הבדיקות של פונקציות הטקסט: `node scripts/check.mjs` (נדרש Node 23.6 ומעלה).
- לבדיקת המבנה של התוסף: `claude plugin validate ./hebrew-rtl`.
- לעדכון HEBREW.md אחרי שינוי ב-`hooks/rules.ts`: `node scripts/build-rules.mjs`.
- לטעינה מתיקייה בזמן פיתוח: `claude --plugin-dir ./hebrew-rtl`.
